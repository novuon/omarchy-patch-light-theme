# Patch Light

Instrument-panel paper: a cool grey-green ground, black ink and one
signal red.
A precise, restrained Omarchy theme with photoreal audio wallpapers, each
with an intro that plays when you switch to the theme. Its sibling is
[Patch Dark](https://github.com/novuon/omarchy-patch-dark-theme).

```sh
omarchy-theme-install https://github.com/novuon/omarchy-patch-light-theme
```

## Wallpapers

Stylus, Console, Folded Dimension, Crosspoint, Acoustic Core and a plain
framed sheet. Each has a six-second intro in `backgrounds/intros/` that ends on the
still.

## Colours

Every colour is defined exactly, in every file, and text reads at 4.5:1 or
more on the ground.

| Role | Colour | Use | On the ground |
|---|---|---|---|
| background | `#b5bab6` | the ground | 1.0:1 |
| lighter_background | `#c2c6c3` | raised: cards, message blocks | 1.1:1 |
| foreground | `#111412` | text | 9.4:1 |
| light_foreground | `#252926` | secondary text | 7.5:1 |
| muted | `#444945` | muted text | 4.7:1 |
| border | `#9ea39f` | hairlines between panels | 1.3:1 |
| accent | `#b8143a` | signal red: markers, fills, the active state | 3.3:1 |
| selection | `#d58b9a` | selected rows | 1.3:1 |

It was made for Patch, the pro audio environment for Omarchy, and needs
nothing from it.
